# Modern Java Lab

This repository is a collection of hands-on examples and experiments for learning modern Java features (Java 21+).

## Modules

- **[01-Virtual Threads](./01-virtual-threads/README.md)**: Explore lightweight concurrency, scalability, and non-blocking behavior.
- **[02-NIO (Planned)](#)**: asynchronous I/O and file system operations.
- **[03-Functional Java (Planned)](#)**: Lambdas, Streams, and Functional Interfaces.

## Project Structure

Each module is contained in its own directory with a dedicated `README.md` and `src/` folder. We use manual compilation to keep the learning process transparent.

### Global Prerequisites

- **Java 21+**: Ensure your `JAVA_HOME` points to a modern JDK.
- **Git**: For version control.
